# VOIDRUN
A fast paced arcade game where you dodge enemies, survive as long as possible, and beat your high score.
CONTROLS :
WASD FOR MOVEMENT 
SHIFT FOR BOOSTING
Q AND E FOR TILTING 
LEFT CLICK TO SHOOT
SPACE TO GO UP
LEFT CONTROL TO GO UP
V TO SWITCH FROM FIRST TO THIRD PERSON POV
Thats it ENJOY THE GAMEE!!!!
